(으)로 · Toward / By / With

Direction (toward), means of transport (by bus), tool (with chopsticks), language (in Korean), material (made of wood).

After a final consonant → 으로. After a vowel or ㄹ → 로.

왼쪽 + 으로 → 왼쪽으로. 버스 + 로 → 버스로. 서울 + 로 → 서울로 (ㄹ takes 로).

Examples

Read, listen if you can, then write each one in the boxes.

왼쪽으로 가세요.
oenjjogeuro gaseyo.
Go to the left.
왼쪽으로가세요.
버스로 가요.
beoseuro gayo.
I go by bus.
버스로가요.
서울로 가요.
seoullo gayo.
I go to Seoul.
서울로가요.
젓가락으로 먹어요.
jeotgarageuro meogeoyo.
I eat with chopsticks.
젓가락으로먹어요.
한국어로 말해요.
hangugeoro malhaeyo.
I speak in Korean.
한국어로말해요.

Try it: write 으로 or 로

  1. 오른쪽＿＿ 가세요. — Go to the right.
  2. 지하철＿＿ 가요. — I go by subway.
  3. 연필＿＿ 써요. — I write with a pencil.
  4. 집＿＿ 가요. — I go home (toward home).
  5. 영어＿＿ 말해요. — I speak in English.
  6. 학교＿＿ 걸어가요. — I walk to school.
Answers

1. 으로 · 2. 로 · 3. 로 · 4. 으로 · 5. 로 · 6. 로
